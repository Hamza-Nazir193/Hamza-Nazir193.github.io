# Hamza Bin Nazir - Portfolio

Professional responsive portfolio website built with HTML, CSS and JavaScript.

## Included
- 11 projects
- 6 projects with real screenshots supplied in the project screenshots document
- Responsive mobile navigation
- Click-to-enlarge project screenshots
- Download CV button
- Clickable Email, Phone, LinkedIn and GitHub contact links
- Smooth, modern responsive design

## Run locally
1. Open this folder in VS Code or Visual Studio.
2. Open `index.html`.
3. With Live Server installed, right-click `index.html` and choose **Open with Live Server**.
4. The site will open in your browser.

## Main files
- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/Hamza_Bin_Nazir_CV.pdf`
- `assets/projects/` - project screenshots
